Marketing Cloud Setup Guide

Create a read-only Installed Package in Marketing Cloud — takes about 5 minutes, done once per org. After setup, every future audit is a single click.

Step-by-step instructions ⏱ ~5 minutes
1
Log in to Marketing Cloud Setup
In the top-right corner of Marketing Cloud, click your name (or the account icon) → Setup. This opens the Admin Setup area — it's separate from the main MC navigation bar.
Your Name → Setup
2
Navigate to Installed Packages
In the left sidebar under Platform Tools, expand Apps and click Installed Packages.
Setup → Platform Tools → Apps → Installed Packages
3
Create a New Package
Click New (top right of the Installed Packages list). Give it a name like "SF Health Audit" and an optional description. Leave all other settings as default. Click Save.
Installed Packages → New → Name: "SF Health Audit" → Save
4
Add an API Integration Component
Inside the new package, click Add Component. Select API Integration as the component type, then select Server-to-Server as the integration type. Click Next.
Package → Add Component → API Integration → Server-to-Server → Next
5
Grant the Required Read Permissions
On the scopes screen, enable Read access for each of the following. The audit is completely read-only — it never writes to your org.
✓ Journeys — Read
✓ Automations — Read
✓ Email — Read
✓ Contacts — Read
✓ Tracking & Analytics — Read
✓ Accounts — Read
Click Save when done.
6
Copy Your Credentials
After saving, the package detail page shows your credentials. Copy all three values:
Client IDAlphanumeric string — copy exactly as shown
Client SecretClick Show to reveal, then copy it immediately
REST Base URILooks like https://mcXXXXX.rest.marketingcloudapis.com
These credentials are saved encrypted in SF Health Dashboard. You only enter them once — all future audits reconnect automatically with your MID or EID.
7
Find Your MID / EID (optional but recommended)
Still in Setup, go to Company Settings → Account Management. You'll see a table of Business Units. The number in the MID column for your BU is what to enter. The top-level row shows your Enterprise ID (EID).
Setup → Company Settings → Account Management → MID column
Having your MID/EID lets you reconnect instantly in future sessions — just enter your MID instead of re-entering the full credentials.

Ready to run your audit?

Connect your Marketing Cloud org using the credentials you just copied. It takes under 2 minutes to get a full health score.
