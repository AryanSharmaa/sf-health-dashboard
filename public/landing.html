Security & Privacy

Your data never leaves Salesforce

We use Salesforce's official OAuth 2.0 flow with PKCE. We read metadata to score your org — we never write anything, never store your data, never see your password.

🔐
OAuth 2.0 + PKCE
Industry-standard OAuth with Proof Key for Code Exchange. No passwords ever transmitted to our servers.
👁️
Read-only access
We only read metadata — Apex classes, Flows, settings. We never create, update, or delete anything in your org.
⏱️
8-hour sessions
Access tokens expire automatically. Revoke access instantly at any time from Salesforce Setup → Connected Apps.
🗑️
No data retention
Only scores and recommended actions are stored — never raw org data, never customer records, never PII.
