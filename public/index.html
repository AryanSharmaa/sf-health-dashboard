Connect Marketing Cloud

Paste your Installed Package credentials below to connect.

Scopes audit to a specific BU
Scopes audit to parent account

MID takes priority over EID if both are entered. Leave both blank to use the default account.

You need to create a free Installed Package in Marketing Cloud once. It takes about 5 minutes and gives this tool read-only API access to your account.
1
Log in to Marketing Cloud Setup
In the top-right corner of MC, click your name → Setup. This opens the Admin Setup area (different from the main MC navigation).
Your Name → Setup
2
Navigate to Installed Packages
In the left sidebar under Platform Tools, expand Apps and click Installed Packages.
Setup → Platform Tools → Apps → Installed Packages
3
Create a New Package
Click New (top right). Give it a name like "SF Health Audit" and a description. Leave all other settings as default. Click Save.
Installed Packages → New → Name: "SF Health Audit" → Save
4
Add an API Integration Component
Inside the package, click Add Component. Select API Integration as the component type, then select Server-to-Server. Click Next.
Package → Add Component → API Integration → Server-to-Server → Next
5
Set the Required Scopes
On the scopes screen, enable Read access for each of these — the audit only needs read permissions:
✓ Journeys
✓ Automations
✓ Email
✓ Contacts
✓ Tracking & Analytics
✓ Accounts
Click Save when done.
6
Copy Your Credentials
After saving, the package page shows your credentials. Copy all three:
Client IDAlphanumeric string — copy exactly as shown
Client SecretClick Show to reveal, then copy
REST Base URILooks like https://mcXXXXX.rest.marketingcloudapis.com
7
Find Your MID / EID (optional but recommended)
Still in Setup, go to Company Settings → Account Management. You'll see a table of Business Units. The number in the MID column for your BU is what to enter. The top-level row shows your EID.
Setup → Company Settings → Account Management → MID column
